# Laravel API Playbook

Select backend-engineer; load api-design, laravel-controllers, laravel-form-request, laravel-api-resource, laravel-policies, laravel-eloquent, and laravel-testing.

1. Define consumer contract, authorization, errors, pagination, and compatibility.
2. Keep the controller as transport mapping; validate with form requests and authorize with policies.
3. Coordinate business work in a service boundary and persistence through deliberate Eloquent or repository use.
4. Transform output with API resources; test contract, validation, authorization, and failure paths.
5. Run change-readiness and security-review.
