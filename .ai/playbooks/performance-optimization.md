# Performance Optimization Playbook

Select backend-engineer or frontend-engineer according to the bottleneck; load performance-baseline and observability.

1. Define a user-impact metric and percentile target.
2. Capture a representative baseline and isolate the dominant bottleneck.
3. Implement the smallest measured improvement.
4. Re-measure, test correctness, and add a regression guard where practical.
5. Record capacity, trade-offs, and monitoring thresholds.
